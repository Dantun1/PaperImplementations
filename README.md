# My Paper Implementations 📝
**A collection of papers recreations, focusing on the full stack of ML/DL. I am focused on understanding the architectures, mathematics and systems-level optimisations behind papers that I am interested in.**

## Structure 
For each paper, I aim to have a folder containing:

1) A "notes" jupyter notebook where I play around with the concepts discussed, implement toy models on real datasets, and experiment.
2) Python modules implementing the key concept(s) discussed.
3) Custom C++/CUDA extensions implementing critical operators for high-performance GPU execution.
